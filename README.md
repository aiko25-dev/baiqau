# Baiqau — Идеядан жеңіске

Қосымша атауы — **baiqau**. Dart пакеті мен Android namespace осы атауға сәйкестендірілген. Android application ID және локалды сақтау кілті бұрынғы орнатуды жаңарту және деректерді сақтау үшін өзгеріссіз қалдырылған.

Байқаулар өткізуге және қатысушылардың жұмыстарын бағалауға арналған қазақша Flutter қосымшасы. Android негізгі платформа, web нұсқасы презентация кезінде алдын ала көруге арналған.

## Іске қосу

Flutter 3.44 / Dart 3.12 немесе үйлесімді жаңа нұсқа қажет.

```powershell
flutter pub get
flutter run
```

Android телефонында USB debugging қосып, USB арқылы жалғаңыз. `flutter devices` арқылы құрылғы ID-сін тексеріп, `flutter run -d <device-id>` орындаңыз.

**Осы Windows бумасында** қазақша жолға байланысты Flutter analyzer қатесін болдырмайтын көмекші бар. Ол файлдарды көшірмей, жобаға ASCII junction жасайды:

```powershell
.\scripts\flutter.ps1 pub get
.\scripts\flutter.ps1 analyze
.\scripts\flutter.ps1 test
.\scripts\flutter.ps1 run -d chrome
.\scripts\flutter.ps1 build apk --debug
```

Дайын demo APK: `build/app/outputs/flutter-apk/app-debug.apk`. Колледждегі қорғауға арналған, жергілікті debug сертификатымен қол қойылады. Google Play жариялауы үшін жеке release keystore қажет.

Android SDK: API 36, Build Tools 36, NDK 28.2.13676358, CMake 3.22.1, JDK 17. SDK осы компьютерде `C:\Users\zdeat\AppData\Local\Android\Sdk` жолына орнатылады. Орта конфигурациясын тексеру: `flutter doctor -v`.

## Қорғау сценарийі

1. **Ұйымдастырушы → Айдана Сәрсен**: «Байқау құру», атауы мен сипаттамасын енгізіп, болашақ мерзімді таңдаңыз, «Байқауды жариялау» басыңыз.
2. Үстіңгі **Demo** батырмасымен **Қатысушы → Аяужан Төлеген** рөліне ауысыңыз. Жаңа байқауды ашып, «Қатысу және жұмыс жіберу» таңдаңыз. Атау, сипаттама, `https://…` сілтемесін толтырыңыз.
3. **Demo → Қазы → Ерлан Әбілов**. «Бағалауды бастау» → жаңа жұмыс. Үш жүгірткіні реттеп, пікір жазып, «Бағаны сақтау» басыңыз.
4. Жұмысты қайта ашып, бағасын өзгертуге болады. **Дана Омарова** немесе **Мұрат Асқар** қазысын таңдап, екінші/үшінші баға қосыңыз. Әр қазының бір жұмысқа бір бағасы сақталады.
5. «Нәтижелер» немесе байқаудағы «Алдын ала рейтинг» арқылы орташа ұпай мен орынды көрсетіңіз.
6. **Ұйымдастырушы** рөліне оралып, байқауды ашыңыз. Әр жұмысқа кемінде бір баға қойылған соң «Нәтижелерді жариялау» қолжетімді болады.
7. Қатысушы «Нәтижелер» бөлімінде қорытынды рейтингті, тұғырды және қазылар пікірін көреді. Қосымшаны жауып қайта ашқанда деректер мен таңдалған қолданушы сақталады.

Нәтиже жарияланғанда қабылдау аяқталып, бағалар бекітіледі. Ұйымдастырушы қабылдауды ертерек аяқтап, бағалау кезеңін бөлек бастай алады. Мерзімі өткен байқау автоматты түрде жаңа жұмыстар қабылдамайды. Жұмыс жіберу байқауға тіркелуді де орындайды.

## Дайын мүмкіндіктер

- Қазақша 11 негізгі экран, Material 3, жұмсақ ақ / күлгін дизайн, offline Manrope қарпі, Android белгішесі және splash.
- 3 рөлге сай навигация, 10 қатысушы мен 3 қазы арасында demo ауысу.
- 5 demo байқау, 11 жұмыс, 16 баға және жарияланған жеңімпаздар.
- Байқау атауы/сипаттамасы бойынша іздеу, санат пен мәртебе сүзгілері.
- Жұмыс жіберу, мерзім және қайталама тіркелу тексеруі; сілтемені көшіру.
- Қазылардың бағалауы, түзетуі және пікірлері; динамикалық рейтинг, алтын/күміс/қола тұғыр.
- Форманы тексеру, сақталу индикаторлары, бос және қате күйлері, сақтау қатесінде деректерді өзгертпеу.
- SharedPreferences ішіндегі нұсқаланған JSON. Demo деректері тек алғашқы іске қосуда жасалады, қате файл автоматты қайта жазылмайды.

Қосымшаның негізгі функциялары интернетсіз жұмыс істейді. Жұмыс файлдары жүктелмейді: олардың сілтемелері сақталады. Demo сілтемелері `example.com` адресіне бағытталған; қорғауда нақты жоба сілтемесін енгізіңіз. Бұл жергілікті demo: әр құрылғының деректері бөлек, серверлік авторизация және синхрондау жоқ.

## Бағалау

```text
Score = (Creativity × 0.40 + Quality × 0.35 + Presentation × 0.25) × 10
```

Критерийлер 0–10, қорытынды 0–100. Бірнеше қазы үшін арифметикалық орташа алынады. Бағаланбаған жұмыстар рейтингке кірмейді; нөлдік баға жарамды. Рейтинг нақты ұпай бойынша кему ретімен, дөңгелектеуге дейін сұрыпталады. Тең ұпайға тең орын беріледі (`1, 1, 3`), теңдіктегі көріну реті жіберу уақыты мен ID арқылы тұрақты.

## Құрылым

```text
lib/
  core/         күндер, санаттар, валидация
  models/       User, Competition, Submission, Evaluation, EvaluationCriteria
  services/     локалды сақтау, бағалау формуласы, рейтинг
  providers/    ChangeNotifier, рөлдер мен бизнес ережелер
  data/         алғашқы demo деректері
  theme/        түстер, типография, Material 3
  widgets/      ортақ карточкалар, badge, бос/қате күйлер
  screens/      барлық экрандар мен навигация
```

Provider әр өзгерісті алдымен сақтау қызметіне жібереді. Сақтау сәтті өткен соң ғана интерфейс деректері өзгереді. Рейтинг UI ішінде есептелмейді: `ScoringService` жауап береді.

## Тексеру

```powershell
.\scripts\flutter.ps1 analyze
.\scripts\flutter.ps1 test
.\scripts\flutter.ps1 build apk --debug
.\scripts\flutter.ps1 build web --release
```

Тесттер: формула мен шекаралық ұпайлар, бірнеше қазының орташа бағасы, тең орындар, толық қорғау сценарийі, қайта ашылу, рөлдік шектеулер, бір рет қатысу, мерзім, жариялау шарттары, бекітілген бағалар, жарамсыз сілтемелер, сақтау қатесі және бүлінген JSON. Widget тесттері 320 px телефонда үш рөлдің барлық navigation бөлімдерін және формалар арқылы толық қорғау сценарийін тексереді.

Қаріп лицензиясы: `assets/fonts/OFL.txt` (Manrope, SIL Open Font License).

Осы Windows жүйесінде release AOT компиляторын (`gen_snapshot.EXE`) Application Control саясаты бұғаттады. Қауіпсіздік саясаты өзгертілмеді; demo үшін debug APK пайдаланылады. Release жасауға рұқсат етілген ортада `flutter build apk --release` орындауға болады.
